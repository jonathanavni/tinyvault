### 3.4 D-M8-4 — Dual-era, served concurrently; exact precedence; exact envelopes

the legacy state is process-scoped and affects legacy-shaped requests only. **Message classification:** a message whose `method` begins `notifications/` is a notification; every other message with a `method` is a request;
